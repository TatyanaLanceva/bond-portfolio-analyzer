## 1. Введение и постановка задачи

### Проблема

- На Московской бирже обращается **~2100 рублевых облигаций** (доски TQCB, TQOB)
- Ручной подбор портфеля среди такого количества выпусков **трудоёмок и субъективен**
- Простая доходность YTM не учитывает «справедливый» уровень для конкретной структуры бумаги (срок, рейтинг, купон, цена, тип эмитента)
- Инвестору нужен **инструмент**, который:
  - Автоматически отберёт лучшие бумаги под заданные параметры
  - Оценит, какие выпуски **недооценены** рынком относительно аналогов
  - Визуализирует денежный поток портфеля

### Цель проекта

Разработать **интерактивное веб-приложение** для автоматизированного подбора портфеля рублёвых облигаций с **ML-прогнозом справедливой доходности** и ранжированием выпусков внутри однородных групп.

### Задачи

1. Загрузка актуальных котировок с MOEX ISS в реальном времени
2. Обогащение данных реальными кредитными рейтингами (smart-lab.ru)
3. Реализация 3 стратегий портфеля: Ladder, Barbell, Wheel
4. Разработка ML-модели для прогноза справедливой YTM
5. Ранжирование выпусков по дополнительной доходности относительно модели
6. Визуализация денежного потока с учётом налогообложения
7. Ведение журнала сделок и учёт уже вложенных средств

## 2. Описание данных и их особенностей

### Источник: MOEX ISS (Информационно-статистический сервер)

| Параметр | Значение |
|----------|----------|
| **Доски** | TQCB (корпоративные), TQOB (ОФЗ) |
| **Валюта** | RUB (FACEUNIT=SUR) |
| **Фильтры** | Только активные (STATUS=A), российские (ISIN начинается с RU), с будущей датой погашения |
| **Размер** | ~2100 строк |

### Основные поля

- `ISIN` — международный идентификационный код
- `SHORTNAME` — краткое наименование
- `MATDATE` — дата погашения
- `FACEVALUE` — номинал (₽)
- `COUPONPERCENT` — купонная ставка (%)
- `ACCRUEDINT` — накопленный купонный доход (НКД, ₽)
- `WAPRICE` — средневзвешенная цена (% от номинала)
- `EFFECTIVEYIELD` — эффективная доходность к погашению (YTM, %)

### Особенности данных

- **Аномальные значения YTM:** MOEX иногда возвращает -99.98% или 60628% (технические сбои для коротких/дефолтных бумаг)
- **Отсутствие реальных рейтингов:** ОФЗ → AAA, корпоративные → BBB (заглушка)
- **Амортизируемые выпуски:** некоторые бумаги гасят номинал частями — их нужно исключать для корректного расчёта

### Дополнительный источник: smart-lab.ru

- Парсинг реальных кредитных рейтингов (АКРА, Эксперт РА, НКР, НРА)
- Определение рейтинга по ширине прогресс-бара на странице облигации
- Результат кэшируется в `rating_cache.json` (~1723 ISIN)

## 3. Обработка данных и разделение на train/test

### Pipeline предобработки

```
MOEX ISS → moex_bonds_update.py → bonds_current.csv → load_bonds_data() → очистка
```

### Этапы

1. **Загрузка CSV** — чтение файла, имена колонок → верхний регистр, удаление пробелов
2. **Проверка обязательных полей** — ISIN, SHORTNAME, RATING, YEARS_TO_MATURITY, DIRTY_PRICE_RUB, YTM_PCT, COUPONPERCENT, FACEVALUE, MATDATE
3. **Приведение типов** — `pd.to_numeric()`, пропуски: COUPONPERCENT → 0, FACEVALUE → 1000
4. **Фильтрация**:
   - Только российские эмитенты (ISIN начинается с RU)
   - Торгуемые (DIRTY_PRICE_RUB > 0)
   - Положительная доходность (YTM_PCT >= 0)
   - Непросроченные (YEARS_TO_MATURITY > 0)
5. **Расчёт признаков:**
   - `LASTPRICE` = DIRTY_PRICE_RUB / FACEVALUE × 100 (цена в % от номинала)
   - `RATING_SCORE` — текстовый рейтинг → числовой (0=AAA … 16=CCC)
   - `IS_GOVERNMENT` — флаг ОФЗ
   - `MOD_DURATION` — модифицированная дюрация
   - `COUPONS_REMAINING` — число оставшихся купонных выплат
6. **Фильтрация выбросов YTM** (только для ML): диапазон [0, 50]%

### Итоговый датасет

| Параметр | Значение |
|----------|----------|
| Исходное число строк (MOEX) | ~2120 |
| После фильтрации (core.load_bonds_data) | ~1830 |
| После фильтрации YTM [0, 50] для ML | ~1770 |
| Отсеяно выбросов | ~60 |
| Признаков для модели | 8 |
| Разделение train/test | 80% / 20% |

### Стратегии портфеля

#### 🪜 Лестница (Ladder)
- Равномерное распределение бюджета по годам погашения (1, 2, 3, 4, 5 лет)
- **Цель:** стабильный поток погашений, снижение процентного риска
- **Плюсы:** предсказуемый денежный поток, реинвестирование при погашении каждой ступени

#### 🏋️ Гантеля (Barbell)
- Инвестиции только в короткие (до 1.5 лет) и длинные (от 4 лет) бумаги
- **Цель:** баланс ликвидности и фиксации высокой доходности
- **Плюсы:** «короткий конец» даёт ликвидность, «длинный» — повышенную доходность

#### 🎡 Колесо (Wheel / Max Yield)
- Покупка самых доходных бумаг в рамках лимитов
- **Цель:** максимальная доходность на заданном горизонте
- **Плюсы:** максимизирует YTM портфеля, подходит для агрессивных инвесторов

#### Общие ограничения
- Максимальная доля одной бумаги (по умолчанию 20% от портфеля)
- Учёт уже вложенных средств (из журнала сделок)
- Фильтрация по минимальному рейтингу и максимальному сроку
- Исключение амортизируемых выпусков (опционально)

## 5. ML-модель: описание и обучение

### Задача

Оценить **«базовую» (справедливую) доходность YTM** по структуре облигации и вычислить **дополнительную доходность** относительно модели:  
`EXCESS_YTM = YTM_фактическая − YTM_прогноз`

Положительное значение → бумага недооценена рынком.

### Архитектура

| Компонент | Описание |
|-----------|----------|
| **Алгоритмы** | RandomForestRegressor / GradientBoostingRegressor |
| **GridSearch** | 5-fold CV, два независимых поиска, победитель по MAE |
| **Scoring** | `neg_mean_absolute_error` (минимизируем абсолютную ошибку) |
| **Масштабирование** | StandardScaler (Z-score нормализация) |
| **Валидация** | 80/20 train/test split (random_state=42) |
| **Финальная модель** | Обучена на **100% данных** с лучшим алгоритмом и гиперпараметрами |

### Признаки (8)

| Признак | Описание |
|---------|----------|
| `YEARS_TO_MATURITY` | Срок до погашения (лет) |
| `COUPONPERCENT` | Купонная ставка (%) |
| `LASTPRICE` | Цена в % от номинала |
| `RATING_SCORE` | Рейтинг-скор (0=AAA … 16=CCC) |
| `FACEVALUE` | Номинал (₽) |
| `IS_GOVERNMENT` | Флаг ОФЗ (1) / корпоративная (0) |
| `MOD_DURATION` | Модифицированная дюрация (годы) |
| `COUPONS_REMAINING` | Число оставшихся купонных выплат |

### Целевая переменная

**`YTM_PCT`** — доходность к погашению (%)

### Процесс обучения

1. Загрузка данных из `bonds_current.csv` через `load_bonds_data()`
2. Preprocessing: расчёт LASTPRICE, инженерия признаков (IS_GOVERNMENT, MOD_DURATION, COUPONS_REMAINING)
3. Фильтрация выбросов YTM: остаются только бумаги с YTM от 0% до 50%
4. Разделение: train 80% / test 20%
5. GridSearch с 5-fold CV:
   - **RandomForestRegressor:** n_estimators [100, 200, 300], max_depth [5, 10, 15, None], min_samples_split [2, 5, 10], min_samples_leaf [1, 2, 4]
   - **GradientBoostingRegressor:** n_estimators [100, 200], max_depth [3, 5, 7], min_samples_split [2, 5], learning_rate [0.05, 0.1, 0.2]
6. Выбор победителя по CV-score (neg_MAE)
7. Оценка на тестовой выборке (R², MAE)
8. Обучение финальной модели на 100% данных с лучшими параметрами
9. Сохранение артефактов: `ml_model.pkl`, `ml_scaler.pkl`, `ml_metrics.json`

### Ранжирование в группах

Выпуски делятся на однородные группы по двум критериям:

1. **Кредитный рейтинг:** AAA–A, BBB, BB и ниже
2. **Срок до погашения:** до 2 лет, 2–5 лет, свыше 5 лет

Внутри каждой группы выпуски ранжируются по **дополнительной доходности (EXCESS_YTM)**.
- **Ранг 1** — лучший кандидат: рынок даёт наибольшую доходность сверх «справедливого» уровня
- **Последний ранг** — бумага переоценена относительно аналогов

## 6. Результаты и применение на практике

### Метрики ML-модели

| Метрика | Значение |
|---------|----------|
| **R²** | **0.79** |
| **MAE** | **2.07 п.п.** |

#### Что такое R² (коэффициент детерминации)?

R² показывает, **какую долю дисперсии** целевой переменной (фактической YTM) объясняет модель. Значение 0.79 означает, что модель учитывает 79% факторов, влияющих на доходность облигации. Оставшийся 21% приходится на ненаблюдаемые факторы:
- рыночный спрос и ликвидность конкретного выпуска;
- макроэкономические ожидания (ключевая ставка, инфляция);
- специфические риски эмитента, не отражённые в рейтинге;
- новостной фон и сантимент рынка.

**Шкала интерпретации R² для финансовых моделей:**
- **>0.85** — отличное качество (редко достижимо на реальных рыночных данных);
- **0.75–0.85** — хорошее качество, модель улавливает основную структуру данных;
- **0.60–0.75** — удовлетворительное качество, модель полезена, но шум значителен;
- **<0.60** — слабая объясняющая способность, требуется добавление признаков.

Наш результат **R² = 0.79** находится в верхней части диапазона «хорошее качество» — модель надёжно разделяет выпуски на «дорогие» и «дешёвые» относительно их фундаментальных характеристик.

#### Что такое MAE (средняя абсолютная ошибка)?

MAE показывает, **на сколько процентных пунктов** прогноз модели в среднем отклоняется от фактической доходности. Значение 2.07 п.п. означает:
- Для облигации с фактической YTM = 15% модель в среднем предскажет значение в диапазоне **15% ± 2.07 п.п.** (от 12.93% до 17.07%);
- Половина прогнозов отклоняется менее чем на 2.07 п.п., половина — более;
- Ошибка измеряется в тех же единицах, что и целевая переменная, поэтому MAE интуитивно понятна.

**Практический смысл MAE = 2.07 п.п.:**

Вспомним формулу: `EXCESS_YTM = YTM_факт − YTM_прогноз`

- Если рынок даёт **больше** доходности, чем прогноз модели → EXCESS_YTM > 0
- Если рынок даёт **меньше** доходности, чем прогноз модели → EXCESS_YTM < 0

Высокая доходность = низкая цена (обратная зависимость). Поэтому, когда рынок требует доходность выше прогноза модели, это сигнал, что рынок видит в данной бумаге **повышенный риск** и «переоценивает» её вниз по цене.

*Пример 1 — рынок переоценивает бумагу (требует премию за риск):*
- Прогноз модели (справедливая YTM): **12%**
- Фактическая YTM на рынке: **15%**
- `EXCESS_YTM = +3 п.п.` — рынок закладывает **премию +3 п.п.** сверх оценки модели
- **→ Бумага «дешевле» прогноза модели: рынок требует повышенную доходность, что может сигнализировать о неучтённых рисках (низкая ликвидность, специфические риски эмитента)** ❌

*Пример 2 — рынок недооценивает риск (бумага «дороже» прогноза):*
- Прогноз модели (справедливая YTM): **12%**
- Фактическая YTM на рынке: **9%**
- `EXCESS_YTM = −3 п.п.` — рынок довольствуется доходностью на **−3 п.п.** ниже оценки модели
- **→ Бумага «дороже» прогноза модели: рынок не требует премию, которую модель считает оправданной** ⚠️

*Чем выше модуль EXCESS_YTM относительно MAE, тем увереннее сигнал.*
Например, EXCESS_YTM = +3.0 п.п. превышает MAE в 3.0 / 2.07 ≈ **1.45 раза** — заметное отклонение от типичного уровня для аналогов.

**Ключевое правило:**
- `EXCESS_YTM > 0` → рынок закладывает премию сверх прогноза модели (бумага «дешевле»)
- `EXCESS_YTM < 0` → рынок не требует премию, которую прогнозирует модель (бумага «дороже»)

**Для инвестора:** ранжирование по убыванию EXCESS_YTM — это способ найти бумаги с максимальной «скидкой» от рынка относительно их фундаментальных характеристик. Но такая скидка не всегда означает «удачную покупку» — она может отражать реальные риски, не учтённые моделью.

### Динамика улучшений

| Версия | Алгоритм | R² | MAE | Что изменилось |
|--------|----------|-----|-----|----------------|

#### Этап v1.0 → v1.1: Инженеррия признаков (Feature Engineering)

**Проблема:** Базовая модель (R²=0.71) не различала ОФЗ и корпоративные облигации, а также не учитывала временну́ю структуру выплат.

**Что сделано:**
1. **IS_GOVERNMENT** — двоичный флаг: 1 для ОФЗ, 0 для корпоративных. ОФЗ систематически имеют более низкую доходность при прочих равных (безрисковый актив), и модель должна это учитывать.
2. **MOD_DURATION** — модифицированная дюрация (чувствительность цены к изменению доходности). Рассчитывается как `YEARS_TO_MATURITY / (1 + YTM/100)`. Добавляет информацию о процентном риске.
3. **COUPONS_REMAINING** — число оставшихся полугодовых купонных выплат до погашения (точный расчёт через MATDATE или приближение `ceil(YEARS × 2)`). Выпуски с одинаковым сроком, но разным купоном, имеют разное число выплат — это влияет на денежный поток.

**Результат:** R² вырос на **+0.06** (с 0.71 до 0.77), MAE снизилась на **−0.58 п.п.** (с 2.80 до 2.22). Feature Engineering дал наибольший прирост качества — правильные признаки важнее сложного алгоритма.

#### Этап v1.1 → v2.0: Оптимизация алгоритма (Gradient Boosting)

**Проблема:** RandomForest усредняет прогнозы множества деревьев, но может упускать тонкие нелинейные зависимости в данных. Остаточная ошибка MAE = 2.22 п.п. всё ещё велика.

**Что сделано:**
1. Добавлен **GradientBoostingRegressor** в GridSearch (5-fold CV) наравне с RandomForest.
2. Параметры бустинга: n_estimators [100, 200], max_depth [3, 5, 7], min_samples_split [2, 5], learning_rate [0.05, 0.1, 0.2].
3. Победитель определяется по **neg_MAE** на кросс-валидации — минимизируем именно абсолютную ошибку, а не квадратичную (MSE), чтобы штрафовать выбросы линейно.

**Почему GradientBoosting оказался лучше:**
- Бустинг строит деревья последовательно, каждое новое дерево исправляет ошибки предыдущего — это позволяет точнее моделировать сложные зависимости (например, нелинейное влияние срока на YTM).
- RandomForest — «параллельный» ансамбль: деревья независимы и усредняются, что даёт более гладкую границу решения, но может терять локальные паттерны.

**Результат:** R² вырос на **+0.02** (с 0.77 до 0.79), MAE снизилась на **−0.15 п.п.** (с 2.22 до 2.07). Прирост скромнее, чем от признаков, но в денежном выражении (на портфеле в миллионы рублей) снижение ошибки на 0.15 п.п. даёт ощутимое улучшение ранжирования бумаг.

#### Практическое применение метрик при подборе портфеля

Метрики модели напрямую влияют на качество ранжирования выпусков:

1. **R² = 0.79** означает, что **79%** различий в доходностях между бумагами объясняются их структурой (срок, рейтинг, купон и т.д.). Это даёт уверенность, что модель не «шумит», а выделяет реальные закономерности.

2. **MAE = 2.07 п.п.** задаёт **порог значимости** для сигнала EXCESS_YTM:
   - `|EXCESS_YTM| < 2.07 п.п.` → шум, бумага оценена рынком «справедливо»;
   - `|EXCESS_YTM| > 3.0 п.п.` → значимое отклонение (превышает MAE в 1.5×);
   - `|EXCESS_YTM| > 4.0 п.п.` → сильный сигнал (превышает MAE в 2×).

3. При формировании портфеля отбираются бумаги с **максимальной положительной EXCESS_YTM** внутри каждой однородной группы (рейтинг × срок). Это позволяет систематически выбирать недооценённые выпуски, минимизируя риск купить «дорогую» бумагу.

### Интерпретация

- **MAE = 2.07 п.п.** — в среднем прогноз отклоняется от факта на 2.07 процентных пункта. Например, для бумаги с фактической YTM = 15% модель в среднем предскажет значение в диапазоне 15% ± 2.07 п.п.
