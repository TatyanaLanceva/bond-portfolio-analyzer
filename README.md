## 🎯 Цель и область применения

Проект решает задачу **автоматизированного построения облигационного портфеля** для розничного инвестора. Вручную подбор облигаций требует анализа сотен выпусков, учёта накопленного купонного дохода (НКД), соблюдения лимитов концентрации и прогнозирования денежных потоков.

Система заменяет ручные расчёты на **воспроизводимый Data Science-пайплайн**, который:

✅ Загружает актуальные рыночные данные с MOEX ISS API  
✅ Очищает данные от аномалий и выбросов  
✅ Применяет алгоритмический подбор с жёсткими бизнес-ограничениями  
✅ Сравнивает классические инвестиционные стратегии (Ladder, Barbell, Wheel)  
✅ Прогнозирует справедливую доходность с помощью **градиентного бустинга**  
✅ Ранжирует выпуски внутри однородных групп по дополнительной доходности  
✅ Строит денежный поток до погашения с учётом налогообложения  
✅ Ведёт журнал сделок и учитывает уже купленные активы  

**Где используется:**  
🎓 Демонстрация компетенций Data Science в финансовой аналитике (дипломная работа)  
💼 Практический инструмент для формирования диверсифицированного портфеля  
📈 Образовательный материал по алгоритмической оптимизации и управлению рисками

## 📥 Источники данных и ETL-пайплайн

### 1️⃣ MOEX ISS API (основной источник)

Датасет `data/bonds_current.csv` формируется на основе открытых данных **Московской Биржи (MOEX ISS API)**.

**Доски:**
- `TQCB` — корпоративные облигации
- `TQOB` — ОФЗ (государственные облигации)

**Фильтры:**
- Только рублёвые облигации (`FACEUNIT=SUR`)
- Только российские ISIN (префикс `RU`)
- Только активные выпуски (`STATUS=A`)
- Только с датой погашения > сегодня

**Поля датасета:**

| Поле | Описание | Тип |
|------|----------|-----|
| `ISIN` | Международный идентификатор выпуска | `str` |
| `SHORTNAME` | Краткое название эмитента | `str` |
| `RATING` | Кредитный рейтинг (AAA → B-) | `str` |
| `YEARS_TO_MATURITY` | Лет до погашения | `float` |
| `DIRTY_PRICE_RUB` | Грязная цена = Чистая цена + НКД (₽) | `float` |
| `YTM_PCT` | Доходность к погашению (Yield to Maturity, %) | `float` |
| `COUPONPERCENT` | Годовая ставка купона (%) | `float` |
| `FACEVALUE` | Номинал облигации (₽) | `float` |
| `MATDATE` | Дата погашения | `datetime` |

### 2️⃣ Smart-lab.ru (опциональный источник рейтингов)

Парсер `smartlab_ratings.py` извлекает кредитные рейтинги (АКРА, Эксперт РА, НКР, НРА) со страниц облигаций на smart-lab.ru. Результаты кэшируются в `data/rating_cache.json`.

## 📊 Предобработка датасета

Исходный CSV-файл с MOEX содержит **~2100 строк** по рублёвым облигациям РФ.

### Этапы предобработки (`load_bonds_data` в `core.py`)

```
1. Загрузка CSV и очистка имён колонок (→ UPPER CASE)
2. Проверка обязательных полей
3. Приведение числовых типов (pd.to_numeric)
4. Заполнение пропусков (COUPONPERCENT → 0, FACEVALUE → 1000)
5. Фильтрация по префиксу ISIN: только RU
6. Фильтрация по цене > 0, YTM ≥ 0, срок > 0
7. Ординальное кодирование рейтинга (AAA=0 … CCC=16)
```

### Фильтрация выбросов YTM для ML-модели

MOEX иногда возвращает аномальные значения доходности (например, **-99.98%** или **60628%**), связанные с техническими сбоями в расчёте эффективной доходности для коротких/дефолтных бумаг. Для ML-модели YTM ограничивается диапазоном **0–50%**, что даёт устойчивое качество предсказаний.

| Параметр | Значение |
|----------|----------|
| Исходное число строк (из MOEX) | ~2123 |
| После фильтрации YTM [0, 50] | ~1768 |
| Отсеяно выбросов | ~355 (17%) |

## 🧮 Алгоритмы оптимизации портфеля

### Жадный алгоритм подбора

Реализован в `build_portfolio()` (`core.py`). Алгоритм последовательно выбирает облигации, максимизируя доходность при соблюдении ограничений.

**Базовые ограничения:**
- Бюджет: `INVESTED_total ≤ Budget`
- Максимальная доля бумаги: `Weight_i ≤ Max_Pct от общего портфеля`
- Минимальный рейтинг: `Rating_i ≥ Min_Rating`
- Максимальный срок: `Years_i ≤ Max_Years`
- Минимальная целевая доходность: `YTM_i ≥ Target_Yield`

### Три стратегии

| Стратегия | Принцип | Особенности |
|-----------|---------|-------------|
| **🪜 Лестница (Ladder)** | Равномерное распределение бюджета по годам (1–5 лет) | Стабильный поток погашений, низкий процентный риск |
| **🏋️ Гантеля (Barbell)** | Только короткие (≤1.5 лет) и длинные (≥4 года) бумаги | Баланс ликвидности и доходности |
| **🎡 Колесо (Wheel/Max Yield)** | Покупка самых доходных бумаг с учётом лимитов | Максимальная доходность на короткой дистанции |

### Добивка остатка

Если после основного алгоритма остаётся >10% бюджета, алгоритм добирает бумаги, не вошедшие в портфель, пока не закончатся средства.

## 🤖 ML-модель: прогноз справедливой доходности

### Архитектура

| Компонент | Описание |
|-----------|----------|
| **Алгоритм** | `HistGradientBoostingRegressor` (scikit-learn) |
| **Тип** | Градиентный бустинг над гистограммными деревьями |
| **max_depth** | 5 |
| **learning_rate** | 0.08 |
| **Early stopping** | Включён (patience=15, validation_fraction=0.12) |
| **Валидация** | 80/20 train/test split (random_state=42) |
| **Масштабирование** | `StandardScaler` |

### Признаки (5)

| Признак | Описание | Тип |
|---------|----------|-----|
| `YEARS_TO_MATURITY` | Срок до погашения (лет) | `float` |
| `COUPONPERCENT` | Купонная ставка (%) | `float` |
| `LASTPRICE` | Цена в % от номинала | `float` |
| `RATING_SCORE` | Рейтинг-скор (0=AAA … 16=CCC) | `int` |
| `FACEVALUE` | Номинал (₽) | `float` |

**Целевая переменная:** `YTM_PCT` — доходность к погашению (%)

### Процесс обучения

```
1. Разделение данных: train (80%) / test (20%)
2. Масштабирование признаков: StandardScaler
3. Базовая модель с early stopping → определение оптимального числа итераций
4. Финальная модель на 100% данных с фиксированным числом итераций
5. Расчёт метрик R² и MAE на тестовой выборке
```

### Результаты обучения (текущие)

| Метрика | Значение | Пояснение |
|---------|----------|-----------|
| **R²** | **0.71** | Модель объясняет 71% дисперсии YTM |
| **MAE** | **2.80 п.п.** | Средняя ошибка прогноза ±2.8 процентных пункта |
| **Итераций** | **124** | Количество деревьев в ансамбле |

### Ранжирование внутри групп

После предсказания YTM бумаги разбиваются на **однородные группы** по двум критериям:

1. **Кредитный рейтинг:**
   - AAA–A (скор 0–5)
   - BBB (скор 6–9)
   - BB и ниже (скор 10+)

2. **Срок до погашения:**
   - До 2 лет
   - 2–5 лет
   - Свыше 5 лет

Внутри каждой группы вычисляется **дополнительная доходность** (фактическая YTM − прогноз модели) и присваивается **ранг** (1 — наибольшая доп. доходность).

**Интерпретация:**
- Положительная доп. доходность → рынок даёт больше, чем типично для похожих бумаг
- Ранг = 1 → лучший кандидат в своей группе

## 📊 Метрики оценки качества

### 1️⃣ Метрики эффективности алгоритма подбора

| Метрика | Описание | Целевое значение |
|---------|----------|------------------|
| **Budget Utilization** | Процент использованного бюджета | ≥ 90% |
| **Constraint Satisfaction** | Соблюдение всех ограничений | 100% |
| **Diversification Ratio** | Количество уникальных выпусков | ≥ 3 |
| **Execution Time** | Время расчёта портфеля | < 1 секунда |

### 2️⃣ Финансовые метрики качества

| Метрика | Формула | Интерпретация |
|---------|---------|---------------|
| **Portfolio YTM** | `Σ(YTM_i × Weight_i)` | Средневзвешенная доходность портфеля |
| **Risk Duration** | `Σ(Years_i × Weight_i)` | Средневзвешенный срок (риск) |
| **Annual Coupon** | `Σ(Coupon_i × Qty_i)` | Годовой купонный доход (₽) |
| **Concentration** | `Max(Weight_i)` | Риск концентрации |

### 3️⃣ Метрики ML-модели

| Метрика | Формула | Описание | Диапазон |
|---------|---------|----------|----------|
| **R²** | `1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−ȳ)²` | Доля объяснённой дисперсии | [0, 1], чем ближе к 1 — тем лучше |
| **MAE** | `Σ|yᵢ−ŷᵢ| / n` | Средняя абсолютная ошибка (п.п.) | ≥ 0, чем меньше — тем лучше |

### 4️⃣ Валидация результатов

**Корректность алгоритма** проверяется через:

1. **Инварианты:**
   - `Σ(Invested_i) ≤ Budget`
   - `Weight_i ≤ Max_Pct` для всех бумаг
   - `Rating_i ≥ Min_Rating` для всех бумаг

2. **Консистентность данных:** проверка целостности журнала сделок
3. **Сравнение стратегий:** многокритериальная оценка по YTM, риску, диверсификации

## 🚀 Установка и запуск

### Требования
- Python 3.11+
- pip

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/TatyanaLanceva/bond-portfolio-analyzer.git
cd bond-portfolio-analyzer

# Установить зависимости
pip install -r requirements.txt
```

### Запуск

```bash

streamlit run app.py
```

Приложение будет доступно по адресу: **http://localhost:8501**

```bash
# Запустить обучение (требуется bonds_current.csv в папке data/)
python src/ml_model.py
```

Результаты обучения сохраняются в:
- `data/ml_model.pkl` — обученная модель
- `data/ml_scaler.pkl` — StandardScaler
- `data/ml_metrics.json` — метрики и архитектура

```bash

python -c "from src.moex_bonds_update import save_moex_bonds_csv; save_moex_bonds_csv()"

# С парсингом рейтингов smart-lab.ru
```

## 🎓 Заключение

Проект **Bond Portfolio Analyzer** представляет собой законченное Data Science-решение для автоматизированного управления облигационным портфелем. Система объединяет:

- **ETL-пайплайн** для получения рыночных данных
- **Feature Engineering** и предобработку с фильтрацией выбросов
- **Жадный алгоритм** оптимизации с тремя стратегиями
- **ML-модель** (градиентный бустинг) для прогноза справедливой доходности
- **Ранжирование** выпусков внутри однородных групп
- **Интерактивный UI** с аналитикой и визуализациями

Ключевое отличие от аналогов — **прозрачность алгоритмов** (жадный подбор с понятной логикой) в сочетании с **ML-ранжированием**, которое помогает выявить недооценённые рынком бумаги.
