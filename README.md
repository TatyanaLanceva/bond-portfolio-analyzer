## О проекте

**Bond Portfolio Analyzer** — интерактивное веб-приложение на Streamlit для:

1. **Загрузки актуальных котировок** с Московской биржи (MOEX ISS) по всем рублёвым облигациям (доски TQCB и TQOB).
2. **Формирования портфеля** по одной из трёх стратегий (Ladder, Barbell, Wheel) с учётом бюджета, кредитного рейтинга, срока до погашения и целевой доходности.
3. **ML-прогнозирования справедливой YTM** с помощью RandomForestRegressor и ранжирования выпусков внутри однородных групп по дополнительной доходности.
4. **Визуализации денежного потока** (купоны + погашение номинала по годам) с учётом налогового режима.
5. **Ведения журнала сделок**: сохранение покупок, учёт уже вложенных средств, экспорт заявок в CSV.

### Зачем это нужно?

- Ручной подбор облигаций среди ~2100 выпусков на MOEX трудоёмок.
- Простая YTM не учитывает «справедливый» уровень доходности для конкретной структуры бумаги (срок, рейтинг, купон, цена).
- ML-модель помогает отделить переоценённые бумаги от недооценённых и выбрать лучшие в каждой группе риска.

## Источники данных

### MOEX ISS (основной источник)

- **Доски:** TQCB (корпоративные), TQOB (ОФЗ)
- **Валюта:** RUB (FACEUNIT=SUR)
- **Поля:** ISIN, SHORTNAME, MATDATE, FACEVALUE, COUPONPERCENT, ACCRUEDINT (НКД), WAPRICE (средневзвешенная цена), EFFECTIVEYIELD (YTM)
- **Фильтрация:** только активные (STATUS=A) российские (ISIN начинается с RU) бумаги с датой погашения в будущем

**Расчёт грязной цены:**
```
DIRTY_PRICE_RUB = FACEVALUE × WAPRICE / 100 + ACCRUEDINT
```

### smart-lab.ru (опционально)

- Парсинг реальных кредитных рейтингов (АКРА, Эксперт РА, НКР, НРА)
- Определение рейтинга по ширине прогресс-бара на странице облигации
- Результаты кэшируются в `data/rating_cache.json`
- По умолчанию для корпоративных бумаг используется заглушка `BBB`

**Маппинг ширины прогресс-бара → рейтинг:**

| Ширина | Рейтинг |
|--------|---------|
| 100%   | AAA     |
| 95%    | AA+     |
| 90%    | AA      |
| 85%    | AA-     |
| 80%    | A+      |
| 75%    | A       |
| 70%    | A-      |
| 65%    | BBB+    |
| 60%    | BBB     |
| 55%    | BBB-    |
| <55%   | BB+     |

### MOEX bondization (амортизация)

- API: `iss.moex.com/iss/statistics/engines/stock/markets/bonds/bondization/{ISIN}`
- Определяет, есть ли у выпуска события амортизации номинала (не только финальное погашение)
- Результаты кэшируются в `data/amortizing_cache.json` (TTL: 24 часа)

## Стратегии портфеля

### 🪜 Лестница (Ladder)

Равномерное распределение бюджета по годам погашения (1, 2, 3, 4, 5 лет).

- **Цель:** стабильный поток погашений, снижение процентного риска.
- **Механизм:** бюджет делится на 5 равных частей, для каждого года выбирается лучшая бумага.
- **Плюсы:** предсказуемый денежный поток, реинвестирование при погашении каждой ступени.

### 🏋️ Гантеля (Barbell)

Инвестиции только в короткие (до 1.5 лет) и длинные (от 4 лет) бумаги.

- **Цель:** баланс ликвидности и фиксации высокой доходности.
- **Механизм:** по 25% бюджета на 2 лучшие короткие + 2 лучшие длинные бумаги.
- **Плюсы:** «короткий конец» даёт ликвидность, «длинный» — повышенную доходность.

### 🎡 Колесо (Wheel / Max Yield)

Жадный алгоритм: покупка самых доходных бумаг в рамках лимитов.

- **Цель:** максимальная доходность на заданном горизонте.
- **Механизм:** топ-8 бумаг по YTM, на каждую ~1/6 бюджета, остаток добивается лучшими доступными.
- **Плюсы:** максимизирует YTM портфеля, подходит для агрессивных инвесторов.

**Общие ограничения:**
- Максимальная доля одной бумаги (по умолчанию 20% от портфеля)
- Учёт уже вложенных средств (из журнала сделок)
- Фильтрация по минимальному рейтингу и максимальному сроку

## ML-модель

### Задача

Оценить **«базовую» (справедливую) доходность YTM** по структуре облигации (срок, купон, цена, рейтинг, номинал, тип эмитента) и посчитать **дополнительную доходность** относительно модели:

```
Дополнительная доходность (EXCESS_YTM) = Фактическая YTM − Прогноз модели
```

Внутри однородных групп (класс рейтинга × корзина срока) выпуски **ранжируются** по EXCESS_YTM — это позволяет сравнивать кандидатов и выбирать наиболее недооценённые.

### Признаки

| Признак | Описание | Тип |
|---------|----------|-----|
| `YEARS_TO_MATURITY` | Срок до погашения (лет) | Числовой |
| `COUPONPERCENT` | Купонная ставка (%) | Числовой |
| `LASTPRICE` | Цена в % от номинала | Числовой |
| `RATING_SCORE` | Рейтинг-скор (0=AAA … 16=CCC) | Числовой |
| `FACEVALUE` | Номинал (₽) | Числовой |
| `IS_GOVERNMENT` | Флаг ОФЗ (1) / корпоративная (0) | Категориальный |
| `MOD_DURATION` | Модифицированная дюрация (годы) | Числовой |
| `COUPONS_REMAINING` | Число оставшихся купонных выплат | Числовой |

**Целевая переменная:** `YTM_PCT` — доходность к погашению (%).

### Архитектура модели

| Компонент | Описание |
|-----------|----------|
| **Алгоритм** | `RandomForestRegressor` (scikit-learn) — ансамбль решающих деревьев |
| **GridSearch** | 5-fold CV по n_estimators, max_depth, min_samples_split, min_samples_leaf |
| **Scoring** | Отрицательная MAE (минимизируем абсолютную ошибку) |
| **Масштабирование** | `StandardScaler` (Z-score нормализация) |
| **Валидация** | 80/20 train/test split (random_state=42) |
| **Финальная модель** | Обучена на 100% данных с лучшими гиперпараметрами |

### Процесс обучения

1. Данные разделяются на train (80%) и test (20%).
2. Все признаки масштабируются через `StandardScaler`.
3. GridSearch с 5-кратной кросс-валидацией подбирает оптимальные гиперпараметры по MAE.
4. Лучшая модель оценивается на тестовой выборке (R² и MAE).
5. Финальная модель обучается на **100% данных** с теми же гиперпараметрами.
6. Артефакты сохраняются: модель (`pickle`), скейлер (`pickle`), метрики (`JSON`).

### Гиперпараметры (GridSearch)

```python
param_grid = {
    'n_estimators': [100, 200, 300],
    'max_depth': [5, 10, 15, None],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4],
}
```

### Метрики

#### R² (коэффициент детерминации)

**Доля дисперсии YTM, объяснённая моделью.**

- 1.0 = идеальное предсказание
- 0.0 = модель предсказывает среднее значение
- <0 = модель хуже предсказания среднего

**Интерпретация:** R² = 0.77 означает, что модель объясняет 77% разброса доходностей облигаций. Оставшиеся 23% приходятся на факторы, не учтённые в модели (рыночный спрос, ликвидность, макроэкономические условия, специфические риски эмитента).

#### MAE (средняя абсолютная ошибка)

**Среднее отклонение прогноза от фактической YTM в процентных пунктах.**

- Чем ниже, тем точнее прогноз
- Измеряется в тех же единицах, что и целевая переменная (п.п.)

**Интерпретация:** MAE = 2.22 п.п. означает, что в среднем прогноз отклоняется от факта на 2.22 процентных пункта. Например, для бумаги с фактической YTM = 15% модель в среднем предскажет значение в диапазоне 15% ± 2.22 п.п.

#### Текущие результаты

| Метрика | Значение |
|---------|----------|
| **R²** | **0.77** (ранее 0.71) |
| **MAE** | **2.22 п.п.** (ранее 2.80) |

*Улучшение достигнуто за счёт добавления новых признаков (IS_GOVERNMENT, MOD_DURATION, COUPONS_REMAINING) и перехода на RandomForestRegressor с GridSearch.*

### Ранжирование в группах

Выпуски делятся на однородные группы по двум критериям:

1. **Кредитный рейтинг:** AAA–A, BBB, BB и ниже
2. **Срок до погашения:** до 2 лет, 2–5 лет, свыше 5 лет

Внутри каждой группы выпуски ранжируются по EXCESS_YTM (ранг 1 = наибольшая доп. доходность).

**Интерпретация:**
- **Ранг 1** — лучший кандидат в группе: рынок даёт наибольшую доходность сверх «справедливого» уровня
- **Ранг N** (последний) — бумага переоценена относительно аналогов

### Использование ML в UI

На вкладке «🤖 ML-Прогноз» доступно:

1. **Сравнение стратегий** — взвешенная YTM, доп. доходность и ранг для Ladder, Barbell и Wheel при текущих параметрах
2. **Детальный разбор портфеля** — для каждой бумаги: прогноз YTM, доп. доходность, группа, ранг и сигнал (выше/ниже/около модели)

## Обработка датасета

Исходный CSV-файл с MOEX содержит **~2100 строк** по рублёвым облигациям РФ. Этапы предобработки:

### 1. Загрузка и очистка колонок
- Имена колонок приводятся к верхнему регистру, пробелы удаляются
- Проверка наличия обязательных полей: `ISIN, SHORTNAME, RATING, YEARS_TO_MATURITY, DIRTY_PRICE_RUB, YTM_PCT, COUPONPERCENT, FACEVALUE, MATDATE`

### 2. Приведение типов
- Числовые поля конвертируются через `pd.to_numeric`
- Пропуски заполняются: `COUPONPERCENT → 0`, `FACEVALUE → 1000`

### 3. Фильтрация
- Только бумаги с префиксом `RU` (российские эмитенты)
- `DIRTY_PRICE_RUB > 0` (торгуемые бумаги)
- `YTM_PCT ≥ 0` (положительная доходность)
- `YEARS_TO_MATURITY > 0` (непросроченные)
- `MATDATE` не пропущена

### 4. Расчёт признаков
- **LASTPRICE:** цена в % от номинала = `DIRTY_PRICE_RUB / FACEVALUE × 100`
- **RATING_SCORE:** текстовый рейтинг → числовой скор (0=AAA … 16=CCC)
- **IS_GOVERNMENT:** ОФЗ = рейтинг AAA + имя начинается с «ОФЗ»
- **MOD_DURATION:** `YEARS_TO_MATURITY / (1 + YTM_PCT/100)`
- **COUPONS_REMAINING:** точное число полугодовых периодов до MATDATE

### 5. Фильтрация выбросов YTM (только для ML)
- YTM ограничивается диапазоном **0–50%**
- Аномальные значения (например, -99.98% или 60628%) не отражают рыночной ситуации
- После фильтрации остаётся **~1770 строк**

### 6. Итоговый датасет для ML

| Параметр | Значение |
|----------|----------|
| Исходное число строк | ~2100 |
| После фильтрации YTM [0, 50] | ~1770 |
| Отсеяно выбросов | ~330 |
| Признаков | 8 |
| train/test | 80% / 20% |

**Функции:**
- Загрузка существующих позиций → учёт при расчёте новых портфелей
- Просмотр истории (вкладка «📜 Журнал»)
- Очистка журнала (кнопка «🗑️ Очистить журнал сделок»)
- Автоматический пересчёт лимитов: `max_allowed = total_portfolio × max_pct − existing_in_bond`
