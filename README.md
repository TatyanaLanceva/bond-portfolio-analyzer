# 📊 Bond Portfolio Analyzer

**Дипломный проект по Data Science**  
Интерактивная система для формирования, сравнения и прогнозирования облигационных стратегий на российском рынке.

## ✨ Возможности
- 📈 **Сравнение стратегий**: Ladder, Barbell, Wheel с расчетом YTM, риска и диверсификации.
- 💰 **Прогноз Cashflow**: Полный купонный поток до погашения с учетом налогов.
- 🎨 **Интерактивный дашборд**: Фильтрация в реальном времени, графики Plotly, экспорт CSV.
- 🛡 **Управление рисками**: Лимиты на долю эмитента, приоритет доходности, обработка НКД.

# 1. Установка зависимостей

# 2. Подготовка данных (запустите Блок 1 для генерации bonds_current.csv)
