## 🎯 Цель и область применения

Проект решает задачу **автоматизированного построения облигационного портфеля** для розничного инвестора. Вручную подбор облигаций требует анализа сотен выпусков, учёта накопленного купонного дохода (НКД), соблюдения лимитов концентрации и прогнозирования денежных потоков. 

Система заменяет ручные расчёты на **воспроизводимый Data Science-пайплайн**, который:
✅ Загружает актуальные рыночные данные и очищает их от артефактов  
✅ Применяет алгоритмический подбор с жёсткими бизнес-ограничениями  
✅ Сравнирует классические инвестиционные стратегии по метрикам доходности, риска и диверсификации  
✅ Прогнозирует купонный поток до погашения каждой бумаги  
✅ Ведёт журнал сделок и динамически учитывает уже купленные активы при расчёте новых лимитов  

**Где используется:**  
🎓 Демонстрация компетенций Data Science в финансовой аналитике (дипломная работа)  
💼 Практический инструмент для формирования диверсифицированного портфеля  
📈 Образовательный материал по алгоритмической оптимизации и управлению рисками

## 📥 Источники данных (Data Pipeline)

### 1️⃣ Исходные данные
Датасет `data/bonds_current.csv` формируется на основе открытых данных **Московской Биржи (MOEX ISS API)** и содержит:
| Поле | Описание | Тип |
|------|----------|-----|
| `ISIN` | Международный идентификатор выпуска | `str` |
| `SHORTNAME` | Краткое название эмитента | `str` |
| `RATING` | Кредитный рейтинг (AAA → B-) | `str` |
| `MATDATE` | Дата погашения | `datetime` |
| `COUPONPERCENT` | Годовая ставка купона (%) | `float` |
| `DIRTY_PRICE_RUB` | Грязная цена = Чистая цена + НКД | `float` |
| `YTM_PCT` | Доходность к погашению (Yield to Maturity) | `float` |
| `FACEVALUE` | Номинал облигации | `float` |

### 2️⃣ Обработка и подготовка признаков (Feature Engineering)
Перед запуском алгоритмов данные проходят строгий ETL-пайплайн:
```python
# 1. Фильтрация по юрисдикции и ликвидности
df = df[df['ISIN'].str.startswith('RU')]
df = df[(df['DIRTY_PRICE_RUB'] > 0) & (df['YTM_PCT'] >= 0)]

# 2. Ординальное кодирование рейтинга (для алгоритмической сортировки)
RATING_MAP = {"AAA":0, "AA+":1, ..., "B-":15, "CCC":16}
df['RATING_SCORE'] = df['RATING'].map(RATING_MAP).fillna(20)

# 3. Расчёт временных признаков
df['YEARS_TO_MATURITY'] = ((df['MATDATE'] - pd.Timestamp.today()).dt.days / 365.25)

# 4. Валидация типов и обработка пропусков
numeric_cols = ['DIRTY_PRICE_RUB', 'YTM_PCT', 'COUPONPERCENT', 'FACEVALUE']
df[numeric_cols] = df[numeric_cols].apply(pd.to_numeric, errors='coerce')
df = df.dropna(subset=['MATDATE', 'YEARS_TO_MATURITY'])
