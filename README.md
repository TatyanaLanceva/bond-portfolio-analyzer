## 🎯 Цель и область применения

Проект решает задачу **автоматизированного построения облигационного портфеля** для розничного инвестора. Вручную подбор облигаций требует анализа сотен выпусков, учёта накопленного купонного дохода (НКД), соблюдения лимитов концентрации и прогнозирования денежных потоков. 

Система заменяет ручные расчёты на **воспроизводимый Data Science-пайплайн**, который:
✅ Загружает актуальные рыночные данные и очищает их от артефактов  
✅ Применяет алгоритмический подбор с жёсткими бизнес-ограничениями  
✅ Сравнирует классические инвестиционные стратегии по метрикам доходности, риска и диверсификации  
✅ Прогнозирует купонный поток до погашения каждой бумаги  
✅ Ведёт журнал сделок и динамически учитывает уже купленные активы при расчёте новых лимитов  

**Где используется:**  
🎓 Демонстрация компетенций Data Science в финансовой аналитике (дипломная работа)  
💼 Практический инструмент для формирования диверсифицированного портфеля  
📈 Образовательный материал по алгоритмической оптимизации и управлению рисками

## 📊 Метрики оценки качества системы

Поскольку проект реализует **алгоритмическую оптимизацию** (а не ML-модель), качество оценивается по следующим критериям:

### 1️⃣ Метрики эффективности алгоритма
| Метрика | Описание | Целевое значение |
|---------|----------|------------------|
| **Budget Utilization** | Процент использованного бюджета | ≥ 90% |
| **Constraint Satisfaction** | Соблюдение всех ограничений (лимиты концентрации, рейтинг, срок) | 100% |
| **Diversification Ratio** | Количество уникальных выпусков в портфеле | ≥ 3 |
| **Execution Time** | Время расчёта портфеля | < 1 секунда |

### 2️⃣ Финансовые метрики качества
| Метрика | Формула | Интерпретация |
|---------|---------|---------------|
| **Portfolio YTM** | `Σ(YTM_i × Weight_i)` | Средневзвешенная доходность портфеля |
| **Portfolio Duration** | `Σ(Duration_i × Weight_i)` | Средневзвешенный срок (метрика риска) |
| **Annual Coupon Yield** | `Σ(Coupon_i × Quantity_i)` | Прогнозируемый годовой купонный доход |
| **Concentration Risk** | `Max(Weight_i)` | Максимальная доля одной бумаги (риск концентрации) |

### 3️⃣ Метрики сравнения стратегий
Для сравнения стратегий (Ladder, Barbell, Wheel) используется **многокритериальная оценка**:
- **Доходность**: чем выше YTM, тем лучше
- **Риск**: оптимальный диапазон срока 2-5 лет (баланс между волатильностью и доходностью)
- **Диверсификация**: больше бумаг → ниже идиосинкразический риск
- **Ликвидность**: регулярность купонных выплат (оценивается по cashflow-календарю)

### 4️⃣ Валидация результатов
**Корректность алгоритма** проверяется через:
1. **Unit-тесты**: проверка граничных условий (пустой пул, недостаточный бюджет)
2. **Инварианты**: 
   - `Σ(Invested_i) ≤ Budget`
   - `Weight_i ≤ Max_Pct` для всех бумаг
   - `Rating_i ≥ Min_Rating` для всех бумаг
3. **Сравнение с эталоном**: ручные расчёты для малых выборок (5-10 бумаг)
4. **Консистентность данных**: проверка целостности журнала сделок
