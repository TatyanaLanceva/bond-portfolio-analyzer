# Bond Portfolio Analyzer

Анализатор облигационных портфелей с прогнозом доходности и рейтингом выпусков.

## Новый функционал:
- Добавлены новые признаки для модели ML: 
  - флаг ОФЗ/корпоративная
  - модифицированная дюрация
  - число оставшихся купонных выплат
- Переписан алгоритм на RandomForestRegressor с GridSearch
- Улучшена точность предсказаний:
  - R²: 0.77 (ранее 0.71)
  - MAE: 2.22 п.п. (ранее 2.80)
